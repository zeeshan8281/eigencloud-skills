⚙️ Setup

~/.cursor/mcp.json or claude_desktop_config.json 
{
  "mcpServers": {
    "eigencompute": {
      "command": "eigen-mcp"
    }
  }
}

🔧 Available Tools

eigencompute_deploy
Deploy Docker image to TEE
eigencompute_list
List all deployed apps
eigencompute_info
Get app status and IP
eigencompute_logs
View app logs
eigencompute_start
Start stopped app
eigencompute_stop
Stop running app
eigencompute_terminate
Destroy app permanently
eigencompute_env_set
Set sealed secrets
eigencompute_upgrade
Upgrade running app
eigencompute_whoami
Check CLI auth status

📋 Prerequisites

Install and authenticate the ecloud CLI:

npm install -g @layr-labs/ecloud-cli@latest ecloud auth login ecloud auth whoami
